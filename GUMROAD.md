## Product Description (ready to paste)

TPT Fleet Autonomy Suite is a desktop environment for the full lifecycle of robot and drone fleets.

It provides:

- Fleet and robot definition management
- Simulation-to-deployment workflow
- Skill registry and basic shared learning
- Sensor visualisation and fusion
- Local database for fleet state and history
- Capability-based security model

Everything runs on your machines or local network. No cloud account required, no telemetry, no subscription.

You receive pre-built native binaries for Windows, macOS and Linux together with a license key file.

This is a one-time purchase. No updates are promised. You may submit approved error reports that may influence a future major release.
